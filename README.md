# TS Pokedex 🐾

An interactive, command-line based (CLI) Pokedex program written in **TypeScript**.

> **Note:** This project was developed as part of the [boot.dev](https://boot.dev) curriculum. It focuses on learning and applying core concepts such as asynchronous programming, network requests, local caching, and building a custom REPL (Read-Eval-Print Loop).

## 🌟 Features

* **Interactive REPL:** A custom command-line interface to enter commands and navigate the Pokémon world.
* **PokeAPI Integration:** Fetches live data such as Pokémon locations, names, and base stats from the [PokeAPI](https://pokeapi.co/).
* **Intelligent Caching:** A built-in caching system temporarily stores previously fetched network data to reduce API calls and speed up response times.
* **Type Safety:** Fully developed in TypeScript for structured, robust, and maintainable code.
* **Unit Tests:** Automated tests ensure system stability (implemented with Vitest).

## 🚀 Installation & Setup

Make sure you have [Node.js](https://nodejs.org/) installed on your system (check the `.nvmrc` file for the recommended Node version).

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/joschi63/TS_Pokedex.git](https://github.com/joschi63/TS_Pokedex.git)
   cd TS_Pokedex
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Usage:**
   ```bash
   npm run dev
   ```
   Once the Pokedex prompt appears, you can use commands like help, map, explore, and catch to start your adventure!
4. **Run tests:**
   ```bash
   npm run test
   ```
